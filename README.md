# Transport Telemetry

Система GNSS-мониторинга общественного транспорта. MVP включает один физический трекер, сервер, веб-карту и симулятор.

## Рабочие документы

1. [Карта проекта](docs/PROJECT_MAP.md) — состав системы и потоки данных.
2. [CHECKPOINT](docs/CHECKPOINT.md) — текущая задача и точка продолжения.
3. [Master ICD](docs/icd/README.md) — каталог технических контрактов.
4. [Журнал решений](docs/DECISIONS.md) — статусы и основания решений.

Правила совместной работы описаны в [AGENTS.md](AGENTS.md).

## Системные требования

[SRS](docs/SRS.md) — действующий **BASELINE** для системы. [Открытые согласования требований](docs/DECISIONS.md#открытые-согласования-требований) ведутся в журнале решений. Прежние редакции доступны в Git.
