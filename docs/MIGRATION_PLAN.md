# План и карта миграции ICD

**2026-11-09. Этап 3 выполнен по утверждённой структуре.** Этапы 0–2 дали инвентарь [оригиналов](../legacy/MANIFEST.tsv), [полные срезы старой схемы](../baseline-old-schema/README.md) и документы передачи контекста. [Master ICD](icd/README.md) ведёт к четырём тематическим спецификациям. Технические статусы перенесены в пределах явно согласованной области. [SRS v1.1](../legacy/originals/Transport_Telemetry_SRS_v1.1.md) остаётся BASELINE, [v1.2](../baseline-old-schema/Transport_Telemetry_SRS_v1.2_DRAFT_r4.md) — DRAFT.

## Проверка переноса

- Сверяются разделы §1–23, адреса относительных ссылок, таблицы форматов и сценарии `DIA-*`, `DIAG-*` и `JRN-*`.
- Исторический снимок и оригиналы сверяются по [контрольным суммам исходного пакета](../CHECKSUMS.sha256) и [манифесту оригиналов](../legacy/MANIFEST.tsv). Контрольные суммы рабочих файлов в исходном пакете относятся к состоянию до этапа 3.
- Для продолжения работы используется [CHECKPOINT](CHECKPOINT.md).
