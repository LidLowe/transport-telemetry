# Master ICD

Каталог интерфейсов между трекером, сервером и локальным журналом.

## Телеметрия и история

- ICD-001 · [POSITION_V1](POSITION_V1.md) — передаёт свежую позицию трекера на сервер.
- ICD-004 · [POSITION_LOG_RECORD_V1](POSITION_LOG_RECORD_V1.md) — хранит измерение и результат попытки отправки.
- ICD-005 · [ARCHIVE_TRANSFER](ARCHIVE_TRANSFER.md) — выгружает накопленные записи журнала на сервер.

## Диагностика

- ICD-002 · [TX_SUMMARY](TX_RX_SUMMARY.md#tx_summary) — сообщает статистику первичных попыток отправки.
- ICD-003 · [RX_SUMMARY](TX_RX_SUMMARY.md#rx_summary) — сообщает статистику приёма позиций сервером.
- ICD-007 · [DEVICE_STATUS](DEVICE_STATUS.md) — описывает отдельное сообщение о состоянии трекера.

## Управление

- ICD-006 · [Управление устройством](../SRS.md#46-device-management--security) — собирает требования к командам, конфигурации и OTA до согласования полного контракта.
- [GET_DEVICE_INFO](../DECISIONS.md#get_device_info--запрос-информации-о-трекере) — выделяет получение сведений об устройстве в отдельную операцию.
- [Обмен ключами](../security/KEY_MANAGEMENT.md#установление-и-обновление-ключей) — определяет установление и обновление защищённого контекста трекера.
